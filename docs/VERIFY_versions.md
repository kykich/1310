# Проверка на четырёх версиях проекта (`test1310\versions`)

Тестовый стенд: четыре версии проекта из `G:\9potok\test1310\` собраны в один
git-репозиторий как **ветки** и отдельные **worktree**-папки. Исходные
репозитории `1009`, `1210`, `2309`, `3108` не изменялись.

Подробное описание стенда — `G:\9potok\test1310\versions\README.md`.

## Что где лежит

```
G:\9potok\test1310\versions.git      — bare-репозиторий (объекты, ветки, replace)
G:\9potok\test1310\versions\1009     — worktree, ветка v1009
G:\9potok\test1310\versions\1210     — worktree, ветка v1210
G:\9potok\test1310\versions\2309     — worktree, ветка v2309
G:\9potok\test1310\versions\3108     — worktree, ветка v3108
```

| Ветка | Коммит | Версия |
|---|---|---|
| `v1009` | `d4d8fc6` | веб-чат DeepSeek, сжатие истории |
| `v1210` | `648cf70` | + RAG, MCP, локальная модель |

Истории репозиториев изначально не связаны. Корневые коммиты «привиты» к
предыдущей версии через `git replace --graft`, чтобы `git diff v1009...v1210`
работал как сравнение версий (сами коммиты не переписаны):

```powershell
git --git-dir=G:\9potok\test1310\versions.git replace -l
git --git-dir=G:\9potok\test1310\versions.git merge-base v1009 v1210
# -> d4d8fc6 (коммит v1009)
```

## Как проверить RAG / `/help` / `/review`

1. Запустить сервер: `python rtk_web.py 8123` из `G:\9potok\1310`.
2. В блоке RAG указать `docs:` = нужный worktree, например
   `G:\9potok\test1310\versions\1210`.
3. Проверить:

```text
/help
/help как устроен RAG?
/review                     # последний коммит этой версии
/review v1009 v1210         # сравнение версий (из любого worktree)
```

CLI:

```powershell
cd G:\9potok\1310
python review_pr.py --repo G:\9potok\test1310\versions\1210 `
  --base HEAD~1 --head HEAD --no-rag --model Local --out review.md
```

## Ограничения

- Worktree `1210` — коммит `648cf70`; **незакоммиченные** изменения исходной
  папки `G:\9potok\test1310\1210` в стенд не входят.
- `3108` — другая продуктовая линия (RTCM-консоль), включена как четвёртая
  «версия» для демонстрации; в цепочке она последняя.
- Межверсионные diff'ы большие (79 файлов / ~22 тыс. строк для 1009→1210),
  поэтому в чате они обрезаются; для полного текста — CLI с `--max-tokens`.
- Индекс RAG общий, но поиск ограничен `docs_dir`; после изменения файлов
  версии нужна переиндексация.
- `refs/replace/*` в `versions.git` обязательны для сравнения версий — не
  удалять.
